# ISEE Web Demo - Quick Startup Guide

## 🚀 1-Minute Demo Launch

### Prerequisites
- Python 3.11+ installed
- Git repository cloned
- Terminal access

### Quick Start Commands
```bash
# 1. Navigate to ISEE directory
cd /path/to/ISEE_Meta_Framework

# 2. Switch to demo branch
git checkout demo/web-ui-investor-showcase

# 3. Install dependencies (if not already done)
pip install -r requirements.txt

# 4. Launch demo
python app.py

# 5. Open browser
# Navigate to: http://localhost:5000
```

## 🛠 Troubleshooting

### Common Issues
1. **Port 5000 in use**: Change port in `app.py` line 394: `app.run(port=5001)`
2. **Import errors**: Ensure you're in correct directory and branch
3. **Slow loading**: Use simulation mode for faster demos
4. **Browser compatibility**: Works best in Chrome/Firefox/Safari

### Demo Tips
1. **Practice flow**: Run through demo 2-3 times before presentation
2. **Backup plan**: Have screenshots ready if technical issues arise
3. **Custom queries**: Prepare domain-specific queries for your audience
4. **Time management**: Full demo is 4 minutes, can be shortened to 2 minutes
