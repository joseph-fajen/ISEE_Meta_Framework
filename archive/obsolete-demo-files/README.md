## Why These Files Were Archived

These files described an **outdated complex configuration interface** that contradicts the current simplified isee-ui design:

### Obsolete Approach (These Files)
- Complex investor demo with "42.9x Model Diversity Expansion" messaging
- Manual selection of cognitive frameworks, AI models, and knowledge domains  
- Multiple configuration steps with cost estimation and resource guardrails
- 4-minute demo scripts with step-by-step configuration
- References to specific git branches and API endpoints

### Current Approach (isee-ui)
- **Ultra-simple interface**: Enter query → Click "ANALYZE WITH ISEE"
- **60 automatic LLM calls** with real-time progress indicators
- **Carefully curated models** - no user selection needed
- **Streamlined workflow** - comprehensive analysis without configuration complexity

## Impact of Keeping These Files

These files would **mislead new users** by:
1. Suggesting complex setup procedures that no longer exist
2. Describing manual model/framework selection that isn't available
3. Referencing investor demo flows not relevant to current usage
4. Creating confusion about how the simplified isee-ui actually works
