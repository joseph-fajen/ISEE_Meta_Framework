# Documentation Archive

This folder contains documentation that has been archived due to changes in the ISEE Meta Framework's evolution.

## Archive Categories

### `deprecated/` - CLI-Era Documentation
Contains documentation from when ISEE was primarily a CLI tool (pre-July 2025). These documents may contain outdated workflows, deprecated configuration options, or CLI-specific guidance that is no longer the primary user path.

**Archival Date**: July 17, 2025  
**Reason**: ISEE evolved to Web UI-first approach with CLI as secondary option

### `historical/` - Development History
Contains implementation notes, development summaries, and historical documentation that provides context for the project's evolution but is not needed for current usage.

## Why Documents Were Archived

The ISEE Meta Framework underwent a significant evolution in 2025:

- **Before**: CLI-first tool with complex parameter management
- **After**: Web UI-first platform with simplified user experience
- **Impact**: Much CLI-specific documentation became outdated

## Using Archived Documentation

These documents may still be useful for:
- Understanding the project's evolution
- CLI power-user workflows (still supported)
- Historical context for development decisions
- Reference for deprecated features

## Current Documentation

For up-to-date documentation, see the main `/docs` folder organized by topic:
- `/getting-started/` - User onboarding
- `/configuration/` - Setup and configuration
- `/advanced/` - Power user features
- `/development/` - Developer resources
