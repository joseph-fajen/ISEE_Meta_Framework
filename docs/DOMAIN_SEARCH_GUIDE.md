# Domain Search Enhancement Guide

## Overview

The ISEE Command Wizard now includes powerful domain search capabilities to help you find the perfect domain for your query. This guide explains how to use the enhanced domain search functionality.

## Domain Search Features

### Category Filtering

You can now filter domains by predefined categories. The Command Wizard presents a list of available categories and allows you to select one to narrow down the domains displayed.

Available categories include:
- **Education**: Educational domains related to teaching, learning, and instruction
- **Technology**: Technology-focused domains including software, digital transformation, and AI
- **Business**: Business-related domains for corporate, management, and workplace
- **Design**: Design-oriented domains for UX, creative work, and interfaces
- **Healthcare**: Healthcare domains for medical applications, patient care, and wellness

### Keyword Search

The keyword search feature lets you find domains by searching through:
- Domain names
- Domain descriptions
- Domain keywords

The search is case-insensitive and will match partial words, making it easy to find relevant domains.

### Combined Filtering

You can combine category filtering and keyword searching to find exactly what you need. For example, you could:
1. Filter by the "Technology" category
2. Search for "innovation" within those results

This powerful combination helps you quickly narrow down to the most relevant domains for your query.

## Using Domain Search

When running the Command Wizard, you'll encounter the domain selection step:

1. **Choose a Category (Optional)**: 
   - First, you'll see a list of available categories
   - Enter a category name to filter domains or leave empty to see all

2. **Enter a Search Term (Optional)**:
   - Enter keywords to search for in domain names, descriptions, and keywords
   - Leave empty to see all domains in the current category filter

3. **Select a Domain**:
   - Choose a domain from the filtered list by entering its number
   - The wizard will display details about your selected domain including keywords
   - Related domains will be suggested based on keyword similarity

## Example Workflow

1. Start the Command Wizard
2. Enter your query
3. At the domain selection step:
   - Filter by "Technology" category
   - Search for "learning" within technology domains
   - Select a domain from the filtered results

## Tips for Effective Domain Searching

- **Use Categories First**: Start with a category to narrow down the initial set of domains
- **Use Broad Keywords**: Try general terms like "learning" or "design" to find related domains
- **Check Related Domains**: After selecting a domain, review the suggested related domains
- **View Domain Keywords**: Look at the displayed keywords to understand a domain's focus

## Available Domains

The Command Wizard loads domains from:
- Default domains built into the system
- Additional domain files (with "domain" in the filename and .json extension)

Custom domain files can be added to expand the available domains for specific areas of interest.
