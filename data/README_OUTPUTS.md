# ISEE Framework Data Directory Structure

This directory contains all data files used by the ISEE Meta Framework, organized in a consistent structure.

## Directory Organization

- `/data/output/` - Contains all output files generated by the framework
  - Markdown files (`.md`) - Human-readable output of synthesized ideas
  - JSON files (`.json`) - Machine-readable output for further processing
  - All outputs are automatically saved here with timestamped filenames

- `/data/state/` - Contains state files for saving/restoring framework state
  - JSON files capturing the complete state of the framework
  - Used for resuming work or re-analyzing results with different methods

## File Naming Conventions

- Output files: `isee_result_YYYYMMDD_HHMMSS.{format}`
- State files: User-defined names, typically with `.json` extension

## Usage Notes

1. All output files are automatically saved to the `/data/output/` directory
2. When loading or saving state, you can specify just the filename (without path) and the system will look in the `/data/state/` directory
3. These directories are included in `.gitignore` to prevent accidental commits of large data files

## Examples

```
# Running the framework with default output location
python main.py --query "My query text"
# Output will be saved to data/output/isee_result_YYYYMMDD_HHMMSS.md

# Saving state
python main.py --query "My query" --save-state my_state.json
# State will be saved to data/state/my_state.json

# Loading state and using a different synthesis method
python main.py --load-state my_state.json --synthesize-method cross_pollination
# Will load from data/state/my_state.json
# New output will be saved to data/output/isee_result_YYYYMMDD_HHMMSS.md
```
